# 🧠 Emotion Prediction

> **An NLP-powered Deep Learning web application that predicts the emotion expressed in a text sentence.**

Emotion Prediction is an end-to-end **Natural Language Processing (NLP)** project that uses a **Bidirectional GRU (BiGRU)** deep learning model to analyze text and predict the emotion associated with it.

The project takes a user's sentence, preprocesses it, converts it into a numerical sequence using a tokenizer, passes it through the trained BiGRU model, and returns the predicted emotion along with its confidence score.

The application is also connected to a **FastAPI backend** and deployed on **Render**, turning the trained NLP model into an accessible web application. 🚀

## 🔍 How It Works

The complete prediction pipeline follows these steps:

```text
User Input
    ↓
Text Preprocessing
    ↓
Tokenizer
    ↓
Sequence Padding
    ↓
BiGRU Deep Learning Model
    ↓
Emotion Prediction
    ↓
Confidence Score
    ↓
FastAPI Backend
    ↓
Web Interface
```

### 🧩 Workflow

**1. User Input 💬**
The user enters a sentence into the web application.

**2. Text Preprocessing 🧹**
The input is cleaned and normalized before being passed to the model.

**3. Tokenization 🔤**
The tokenizer converts the text into numerical tokens that can be processed by the neural network.

**4. Sequence Padding 📏**
The token sequence is padded to a fixed maximum length so that it matches the model's expected input format.

**5. BiGRU Model 🧠**
The processed sequence is passed to the trained **Bidirectional GRU** model, which learns contextual information from both directions of the sequence.

**6. Emotion Prediction 🎯**
The model calculates probabilities for the supported emotions and identifies the most probable emotion.

**7. FastAPI ⚡**
The FastAPI backend receives prediction requests, processes the input, and returns the model's result.

**8. Web Interface 🌐**
The prediction and confidence score are displayed to the user through the frontend.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/sohammdikale/Emotion-Prediction.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd Emotion-Prediction
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the FastAPI Application

```bash
uvicorn main:app --reload
```

### 7️⃣ Open the Application

Visit:

```text
http://127.0.0.1:8000
```
